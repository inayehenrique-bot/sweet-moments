Objetivo

Esse site foi desenvolvido para um trabalho escolar com o objetivo de compartilhar receitas de doces, como bolo, brigadeiros e diversas outras coisas delíciosas, ajudando as pessoas descobrir novas receitas e aprender a prepará-las.

Como o Sweet Moments foi criado?

O Sweet Moments foi criado utilizando as linguagens HTML e CSS, pesquisas sobre HTML e CSS, aulas e o livro. O HTML foi utilizado para estruturar as páginas, adicionar textos, imagens, e links para receitas, enquanto o CSS ficou responsável pela parte da aparência visual do site.
